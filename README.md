# 🧮 Calculadora em Java

Projeto desenvolvido durante meus estudos de **Java**, com o objetivo de praticar lógica de programação, estruturas condicionais, loops e entrada de dados com `Scanner`.

## 🚀 Funcionalidades

* Adição (`+`)
* Subtração (`-`)
* Multiplicação (`x` / `X`)
* Divisão (`/`)
* Resultado decimal em divisões
* Tratamento de divisão por zero
* Validação da operação escolhida
* Opção de realizar novas operações usando `S/N`

## 🧠 Conceitos praticados

* `Scanner`
* `if / else if / else`
* `do while`
* Operadores lógicos (`&&` e `||`)
* `charAt(0)`
* Conversão de tipos com `(float)`
* Variáveis `int`, `float` e `char`
* Validação de entrada
* Git e GitHub

## 📌 Objetivo

Continuar evoluindo o projeto conforme avanço nos estudos de Java, adicionando novas funcionalidades e aplicando novos conceitos aprendid
